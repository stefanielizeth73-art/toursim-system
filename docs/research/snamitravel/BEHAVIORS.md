# Snamitravel Behavior Notes

Source checked: https://www.snamitravel.com/

- Header sits fixed over the hero, then shifts into a blurred light dock after scroll.
- Main menu opens as a full-screen cream overlay with large serif uppercase links.
- Hero uses full-bleed media, low-contrast warm overlay, large Bodoni-style headline, and a circular CTA.
- Scroll reveals are mostly fade-up / soft pop-in with slow easing.
- Image areas use subtle scale and parallax movement rather than loud motion.
- Editorial sections alternate light cream backgrounds, black immersive image panels, large serif headings, and restrained gold accents.
- Dialogs use a blurred backdrop and scale/fade entrance.

Adaptation for TourSim:

- Real Snami copy was replaced with personalized tourism, Dijkstra route planning, recommendations, favorites, diary community, and indoor navigation content.
- The video hero was replaced by `static/images/hero_poster.jpg` so a future edited video can drop into the same visual slot.
